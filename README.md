# 采芯助手

电子元器件采购的浏览器工作台：整理询价、比较货源、记录报价和监控库存，并可连接自己部署的团队服务。

由 [imchuckguo](https://github.com/imchuckguo) 维护，基于 MIT 开源项目 [Chip-Annotation](https://github.com/cutepoison888/Chip-Annotation) 改进。[来源与许可证](THIRD_PARTY_NOTICES.md) · [隐私说明](PRIVACY.md) · [团队服务部署](docs/DEPLOYMENT.md)

## 功能

- **采购工具**：在 IC 交易网、正能量和华强电子网辅助识别、复制 QQ 号码，整理批量询价；消息由你自己发送。
- **询价台账**：记录公司、料号、品牌、批次，填写数量、税别、价格、货品与货期；比较同料号有效报价，支持 CSV 和 JSON 导出、迁移导入。
- **货源与监控**：查询立创、云汉、圣禾堂、贸泽、得捷等网站，监控选中商品或料号的库存/价格变化。数据以网站实际显示为准。
- **团队协作**：自己部署后端，使用单次邀请加入，选择记录后加密共享；支持成员权限、暂停、撤回、离线队列和冲突处理。

## 与上游的主要区别

新的采芯品牌与台账界面；报价改为扩展来源隔离页面；内容脚本不直接获得完整本地存储；移除了旧名单上传和团队同步协议；日志默认关闭并脱敏；CSV 公式防护、导入校验和统一版本检查；新增可部署的团队服务与自动化测试。

这些是实现的保护措施，不是“绝对安全”保证。详见[验证边界](docs/VALIDATION.md)。

## 安装 Chrome / Edge 扩展

1. 从 [Releases](https://github.com/imchuckguo/caixin-assistant/releases) 下载 `caixin-assistant-v0.1.0.zip` 并解压到长期保留的目录。
2. 打开 `chrome://extensions`（Edge 用 `edge://extensions`），开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中含 `manifest.json` 的目录，固定采芯助手图标。
4. 与旧版迁移时，避免同时启用两个插件；确认备份后停用旧版，再刷新采购网站页面。选择比价网站前阅读面板中的联网说明。

从源码安装时选择仓库内的 `extension` 目录。不要删除或移动安装目录。当前不包含 Chrome 应用商店上架，未承诺所有 Chromium 变体均经过实机验证。

### 从旧插件迁移

在旧插件中导出询价 CSV，再在采芯助手的“询价记录本 → 导入 CSV / JSON”中导入。导入会先校验，追加到本机；不会自动把历史报价共享到团队。CSV 只包含旧版选择导出的列，缺失字段不能恢复。新 JSON 备份仅包含自己的报价，不包含团队凭据或队友记录。保留旧插件直到确认迁移成功。

## 团队协作

团队服务需要独立部署；GitHub 仓库不是在线数据库，也没有为你配置公共云服务。未配置时，本地采购工具可以使用。

后端使用 Node.js 24.14+ 的 HTTP、crypto 和 SQLite，单实例运行、持久化数据。创建团队需要部署创建凭据；每个成员有独立访问令牌，服务器只存其摘要。邀请默认单次使用、24 小时有效。

报价与敏感名称使用 Web Crypto AES-GCM 加密。服务器仍可见 IP、时间、成员角色和密文元数据；已下载资料无法远程追回。[完整部署和备份步骤](docs/DEPLOYMENT.md)。

## 开发与验证

无需安装 npm 运行时依赖。使用 Node.js 24.14.0+ 和 Python 3（打包 ZIP）：

```sh
npm run check
npm test
npm run package
```

安装包和 SHA-256 校验值生成到 `dist/`。测试使用合成数据、临时数据库和本地 HTTP，不连接真实业务数据库，不发邮件或 QQ 消息。

```sh
node scripts/preview.mjs
```

上面的开发预览提供模拟 Chrome API 与合成报价，只用于检查界面，不是已安装扩展或生产团队服务。

## 目录

| 目录 | 用途 |
| --- | --- |
| `extension/` | 可直接加载的 Manifest V3 扩展 |
| `server/` | 可自行部署的团队 API 与 SQLite 存储 |
| `tests/` | 权限、隐私、加密、数据迁移与协作集成测试 |
| `scripts/` | 语法与边界检查、打包、界面预览 |
| `docs/` | 部署、验证和设计记录 |

## 使用限制

网站改版、登录和人机验证可能使读取失效，插件不绕过验证。库存与报价仅供采购核对，不保证有货、不代表授权分销关系。团队端尚未部署到公网，真实业务环境需要部署者验证 TLS、持久化、访问控制和备份恢复。
