# 采芯助手：云端团队协作规格

状态：用户已于 2026-11-20 批准本规格；先交付完整可部署版本，不创建云资源，不代表已有云服务。

## 目标和架构选择

让多名同事在各自浏览器中共享明确选中的询价记录；本地采购功能不依赖云服务。共享的报价在扩展端加密，在可信扩展页面解密展示。

建议默认交付独立可自行部署的 Node.js 24.14+ 后端、SQLite 持久存储、Docker 配置和 HTTPS 反向代理说明。它不依赖用户现有 CRM、网站或数据库，不预置第三方云账户和地址。使用 Node 内置 HTTP、加密、SQLite 和测试能力，减少初版部署依赖；SQLite 部署为单实例，数据库使用持久卷备份，不伪装成可任意横向扩展的服务。

已考虑的替代方案：

1. 独立后端（推荐）：数据归用户管理、依赖少，需要用户提供服务器或容器平台。
2. 托管数据库与认证平台：运维较少，但要选定供应商、账户、区域和费用；当前没有获得创建这些云资源的批准。
3. 继续仅本地：不能满足用户新增的团队协作目标，不作为最终交付。

本提案采用方案 1。若用户选择方案 2，先更新团队规格及部署边界，再实现相应适配。

## 功能边界

- 创建团队、输入昵称、生成受限邀请、加入团队、查看成员和角色。
- 角色为 owner 和 member。owner 管理邀请与成员；成员只修改/撤回自己的共享记录，不能修改队友记录。
- 明确区分“我的记录”“团队已共享记录”。仅共享用户选择的记录；自动共享为单独开关，初始关闭，开启后默认仅共享新记录。
- 历史记录必须单独勾选后才上传；询价话术默认不共享。共享字段包含公司、QQ、料号、品牌、批次、数量、价格、税别、货品、货期、有效状态与用户明确选择的备注。
- 支持暂停同步、手动同步、失败重试、查看上次同步时间、退出团队、撤销共享和移除成员。
- 不自动发送邀请消息，不发真实邮件，不接管 QQ 发消息。

## 连接与用户控制

用户在团队设置页输入后端地址，查看会发送的数据类型，授权该精确来源，然后主动创建或加入团队。生产连接必须为 HTTPS；仅本地开发允许 localhost/127.0.0.1 的 HTTP 地址。禁止把令牌或邀请放进查询参数、日志和宿主网页；分享文本可包含后端地址、团队标识、一次性邀请和团队密钥，界面提醒持有邀请的人可以加入并读取共享资料。

扩展不预置作者服务器。尚未配置、共享关闭、退出或权限被撤销时，所有启动、计时器和自动同步分支均停止相应团队网络行为，并清理失效的定时器。设置可选来源权限不意味着允许任意网站读取数据；实际请求仅发往用户配置并授权的一个团队后端来源。

## 身份、邀请与访问控制

初版不要求邮箱账户，不实现邮箱发送、第三方登录或自建密码找回。采用每成员独立的高熵访问令牌；这是设备/成员凭据，名称只用于展示，不作为身份认证。

- 团队创建需要部署者提供的独立创建凭据；凭据由部署者安全配置，不写进公开代码、扩展包或演示截图。
- 成员令牌使用加密安全随机数生成，服务器仅存其摘要；请求用 Authorization 头传送，令牌不出现在 URL。
- 邀请单次有效，默认 24 小时到期，可由 owner 撤销；服务器仅保存邀请凭据摘要。
- 每个请求重新检查成员是否有效、所属团队和角色；不能靠客户端传入 teamId/memberId 越权。
- 移除成员立即撤销服务端访问，退出停止本机同步并清除相关凭据及队友缓存；保留用户自己的本地记录。
- 已经下载到对方设备的数据无法远程抹除；初版不承诺撤销历史解密能力或完美前向保密。

## 加密与数据布局

扩展创建独立的 256 位团队密钥，用 Web Crypto 的 AES-256-GCM 加密每条共享记录与敏感名称。每次加密使用新的 96 位随机 IV，并以协议版本、团队 ID 和记录 ID 作为附加认证数据，防止密文跨团队/记录挪用。密钥只保存在可信扩展存储和用户主动交付给同事的邀请材料中，不发给服务器。不得使用团队名称、昵称或短数字口令作为加密密钥。

服务器仍可见 IP、请求时间、成员/团队不透明标识、记录数量、修改版本、密文长度与访问令牌摘要，不能宣传“服务器什么也不知道”。本机解密后的记录不是磁盘加密；受控制的浏览器、恶意扩展或泄漏的团队邀请仍可能导致资料泄漏。

服务端存储团队、成员、邀请、加密记录和版本事件；使用参数化 SQL、事务和团队范围过滤。日志只记录请求结果和错误编号，不记录授权头、邀请材料或业务正文。

## 同步与异常

- 推送、分页拉取、服务器递增修订号、撤回墓碑；有大小和条数上限。
- 本地先保存，上传队列持久化；离线不阻止填写报价。重试采用退避，不无限打开后台页面。
- 服务器校验预期修订号；冲突返回明确结果，保留本地副本，允许用户选择保留哪一版，不默默覆盖。
- 暂停同步保留待处理队列；退出团队不继续发送队列。恢复共享不自动上传所有历史记录。
- 修改后端地址必须断开旧会话并重新加入，不把旧服务器令牌发送给新地址。
- 请求有超时、请求体限制、单记录大小限制、分页限制和限速；未知字段、非法角色、跨团队标识和错误密文均拒绝或明确报错。

## 接口边界

以 /v1 为协议前缀，至少覆盖健康检查、创建团队、生成/撤销邀请、加入、成员查询/移除、记录推送、增量拉取、撤回、退出。每种响应带稳定错误码。HTTP 健康检查不返回机密配置；CORS 只用于限制允许的扩展来源，不能替代身份认证。

扩展的团队模块只处理加解密、可信存储、队列与明确授权的后端通信；内容脚本不能创建团队、获取令牌、读取密钥或触发任意同步请求。连接设置、团队管理与报价编辑只在扩展页面执行。

## 验证与交付

- 本地启动后端，使用合成团队 A/B 和独立成员凭据，测试创建、邀请、加入、共享、拉取、撤回、退出、踢人和重启后的数据保留。
- 检查跨团队访问失败、成员修改他人记录失败、过期/重复/撤销邀请失败、被撤销令牌失效、过大请求被拒绝。
- 加密往返、篡改、错误团队/记录 AAD、错误密钥、随机 IV 及服务器数据库不含测试报价明文。
- 验证同步关闭和旧版遗留配置不外发、退出后不外发、改服务器不泄漏原凭据、离线与冲突不丢失本地报价。
- 交付后端源码、启动命令、Docker 与持久卷说明、HTTPS 部署说明、合成数据端到端测试、备份/恢复说明和部署环境变量示例。真实运行配置、密钥、SQLite 数据库及日志不提交 GitHub。
- 原插件已关闭的旧团队模块不恢复；使用本规格定义的新模块替换，旧状态不能自动激活云同步。
