## 产品与界面方向

- 产品：给电子元器件采购人员使用的浏览器采购工具。
- 性格：克制、明确、便于长时间看表。
- 世界：采购台账、料号目录和库存看板；以灰白表面、深色文字和少量青绿色强调色表现。
- 重点：报价表的有效价格与库存变化承担视觉重点，设置面板保持安静。
- 识别细节：统一的料号文字样式和窄幅状态标记；简单的采芯字标及平面图标，不套用其他公司的标志。

弹窗明确分为采购工具、记录、监控、团队与设置入口，缩短长段说明；记录本提供清晰的表头、价格与数量对齐、键盘焦点和空状态；监控页区分新增、减少、缺货和查询失败。移除紫蓝渐变、装饰性 emoji 和“安全、无后门”等无法保证的宣传语。保留可访问标签、焦点状态与系统减少动态效果支持；字体和图标均本地提供，不加载远程字体或脚本。

## 子项目 A：本地采购功能

保留并回归验证：

1. IC 交易网、正能量和华强电子网的 QQ 类型识别与复制。
2. 批量询价时由用户自己发送消息；插件只整理、复制和打开会话。
3. 询价记录、编辑、有效报价、最低未税价比较与 CSV 导出。
4. 立创、云汉、圣禾堂、贸泽、得捷等现有货源查询及库存价格监控。
5. 页面精简、深色模式和站点查询状态。

网站改版与登录/验证可能导致查询失败；界面应显示失败、保留已有记录并允许重试，不保证真实库存、不绕过验证、不自动发送 QQ 或邮件。

## 报价与凭据隔离

敏感报价只能在扩展自身来源的页面内渲染。采购网站中的实时报价区域改为扩展来源 iframe；网站仅看到空壳、固定入口和本来就在其页面上的料号。不得把报价、供应商列表、团队成员、备注、令牌或密钥写进宿主网站 DOM、data 属性、网页存储、URL 或 postMessage。

跨来源 iframe 不以 Shadow DOM 替代；不提供向网页导出报价的消息接口。需要共享的嵌入资源仅向既有采购站点开放；不得把团队设置页、密钥或后台资源列为网页可访问资源。

报价、团队密钥与同步凭据保存在扩展后台或可信扩展页面能够访问的存储区；使用存储访问级别限制内容脚本。内容脚本通过有来源校验、字段白名单的消息获得必要设置、当前站点监控标识与 QQ 本地标记，不直接获得完整询价记录或团队配置。设置修改同样使用字段白名单。敏感后台操作只接受本扩展页面发出的请求。

本机普通记录仍为本地持久存储，不宣传本机磁盘加密或抵御整个电脑被攻破。团队相关加密另见团队规格。

## 删除旧逻辑与其他修复

- 移除上游名单服务器同步、QQ 分类上传、管理员申诉/提交以及旧版团队同步实现，不依赖隐藏界面或布尔开关来阻止旧路径联网。
- 新安装、本地模式、团队关闭和退出团队均不得触发团队网络请求，即使存在旧版遗留配置或旧计时器。
- 默认不持久记录业务调试日志。若用户主动启用诊断，只记录时间、模块和结果码，不记录公司、QQ、型号、报价、请求正文、邀请、令牌或密钥。
- 用户清空记录时清理相应诊断与历史缓存；清空本机记录和删除云端共享记录分别说明，不以本地清空暗示已撤回队友副本。
- 版本来自统一的打包信息，并检查后台实际响应；保留“后台无响应”和真正版本不一致提示，不靠隐藏警告修复问题。
- 图片代理限制可信图片来源、图片类型、读取体积和超时；拒绝本机文件、回环地址及非 HTTP(S) 协议。
- CSV 导出正确转义引号，并防止用户/网页输入被电子表格当作公式执行。
- 不申请历史、Cookie 读取、本机文件扫描、Native Messaging、调试器或全站常驻访问权限。云端地址采用单独的可选站点授权。

## 数据迁移与兼容

原插件保持原样可用；新产品有独立安装目录和身份，不在后台读取旧插件的私有存储。不发布用户数据或任何浏览器配置目录。提供现有格式兼容说明及显式导入的迁移办法，导入前校验字段和体积，失败不覆盖现有记录。旧版已导出的 CSV 需支持核心报价字段的迁移；新增备份优先使用受校验的 JSON 格式以保留完整字段。
