# 采芯助手本地插件 Implementation Plan

> **For agentic workers:** Implement task by task with available tools once implementation is requested and all applicable approvals are satisfied. Use an available execution skill when helpful; otherwise execute directly. Track progress with checkbox (`- [ ]`) syntax.

**Goal:** 发布有独立品牌、隔离报价、保留采购功能的采芯助手。

**Architecture:** 保留上游站点读取器及监控比较器，收窄后台消息接口。报价仅在扩展页面展示，宿主页面只嵌入扩展 iframe；可信存储不向内容脚本开放。

**Tech Stack:** Chrome Manifest V3、原生 JavaScript/CSS、Node.js 24.14+ 内置测试。

**Spec:** ../specs/2026-11-20-caixin-core-design.md
