# 0.1.0 验证记录

日期：2026-11-20。以下区分实际完成的检查与未验证的环境，不把预览等同于已安装扩展。

## 已完成

- Node.js 24.14.0：`npm run check`，检查所有 JS 语法、清单引用、脚本资源、版本一致性及内容脚本不直接访问私密存储。
- `npm test`：16 项自动测试通过。使用合成数据、本机 HTTP 和临时 SQLite，覆盖 AES-GCM 往返/篡改/错误 AAD、来源规则、CSV 公式防护、迁移校验、团队/角色隔离、单次/过期/撤销邀请、修订冲突、撤回、成员撤销、数据库重启持久化、请求限制、旧配置不联网、消息权限、日志脱敏、离线队列、暂停、权限撤销、未来记录自动共享、并发共享不丢失和监控比较。
- 数据库检查：测试数据库不含合成报价的明文标识或成员原始令牌；只保存密文与认证摘要。
- Chrome 界面预览：弹窗、询价记录本、团队连接页与库存监控空状态显示正常。预览使用模拟 Chrome API，不读取真实浏览器存储。
- 浏览器来源隔离：合成测试页在 127.0.0.1 嵌入 localhost 来源报价 iframe，宿主脚本读取被浏览器同源策略阻止。这验证了跨来源机制；不是已安装 Chrome 扩展的全场景渗透测试。
- `docker compose config --no-env-resolution --quiet` 验证配置结构；没有解析实际部署密钥。
- `npm run package` 生成扩展 ZIP 与 SHA-256；包内是安装资源、许可证和来源说明，无数据库、凭据、业务记录或浏览器配置。

## 未完成的外部环境检查

- 本机 Docker daemon 未启动，未构建镜像或运行容器；Node/SQLite 服务已在本机集成测试中运行。
- 没有部署公网服务器，未验证真实域名、TLS、代理和云端卷恢复。
- 未将此新扩展替换安装到用户现有 Chrome 配置；此前安装的上游插件保持独立。当前提供安装包与安装/迁移步骤。
- 没有在全部真实已登录采购网站逐项回归；网站结构改变、验证码及账户权限可能影响读取。
- 没有独立渗透测试、正式密码学审计或对操作系统被攻破的保护保证。
